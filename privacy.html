Privacy Policy

Effective: 20 November 2026

Operator

ClubHunter is an independent project managed by its application operator. Contact: @club.hunterr on Instagram (direct message).

Information processed

When an operator connects an account, the application may process account identifiers, display names, authorization tokens, selected media, captions, public content metadata and publishing status. The application uses this information to authenticate accounts, prepare content and submit or monitor authorized publishing requests.

Storage and third parties

The desktop workflow stores configuration and project information locally. Connected social platforms receive information needed for authorized API requests. If enabled, OpenAI may receive content metadata or media for analysis, and Apify may process public content metadata for discovery. GitHub Pages hosts this informational website and may process technical connection data under its own privacy policy.

Retention and control

Local project data remains until removed by the operator. Account access can be revoked through the connected platform settings; local tokens and project files can also be deleted. Third-party services apply their own retention policies. Requests concerning access, correction or deletion may be directed to the contact above, subject to applicable law.

Security

Authorization credentials should be kept confidential and must not be posted publicly. No system can guarantee absolute security.
